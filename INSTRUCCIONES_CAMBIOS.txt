BUBBLECOOKIES — ACTUALIZACIÓN PUNTUAL

1) BASE DE DATOS EXISTENTE
- Haz un respaldo de bubblecookies_db antes de modificarla.
- Abre phpMyAdmin > bubblecookies_db > SQL.
- Ejecuta una sola vez el contenido de MIGRACION_METODO_PAGO.sql.
- No importes bubblecookies_db.sql sobre tu base actual: ese archivo es un respaldo completo de referencia.

2) FLASK
- El endpoint de pedidos ahora exige una sesión real de cliente en Flask. La validación no depende únicamente de localStorage.
- La subida de imágenes se guarda en angular/public/assets/uploads, que es la carpeta estática del proyecto Angular.

3) ANGULAR
- En angular ejecuta npm install y después npm start.
- La carpeta node_modules no se incluye en el ZIP; se genera en tu PC.

4) UNIDADES Y COSTOS
- Materia prima registra nombre, unidad base (kg, pza o L) y stock mínimo. La existencia inicia en cero.
- El precio unitario se captura en el formulario de compra y se actualiza como último costo de referencia del ingrediente.
- Las recetas existentes pueden conservar g/ml; producción convierte a la unidad base del inventario antes de descontar.

5) PAGO
- Efectivo o tarjeta simulada. Los campos de tarjeta son temporales en el formulario: no se envían al backend ni se guardan en base de datos, localStorage o sessionStorage. No existe cobro real.
- Se guarda únicamente el método de pago (efectivo/tarjeta) y el folio se muestra en Gracias por tu compra.

6) IMÁGENES
- El proyecto original no incluye una imagen específica de Arcoiris (colores.png). Si esa ruta falla, se muestra una imagen de respaldo para evitar el icono roto. Para mostrar la galleta Arcoiris correcta, sube su imagen desde Productos y recetas.
- Los colores HEX se aplican en las tarjetas de catálogo y en las vistas de producto que muestran su color.

VALIDACIÓN REALIZADA EN ESTE ENTORNO
- Python: compilación sintáctica de flask/app.py correcta.
- TypeScript: comprobación sin emisión correcta.
- Angular Compiler (ngc): compilación de componentes y plantillas correcta.
- No se ejecutó una prueba integral contra MySQL ni el servidor Flask: este entorno no tiene Flask instalado ni conexión a tu base local. La compilación completa con Angular CLI tampoco pudo ejecutarse porque el Node del entorno es v22.16.0 y Angular CLI 22 requiere v22.22.3 o superior.
